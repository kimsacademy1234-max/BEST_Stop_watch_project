## 3. ILA 로 보는 것 — L6 (자리 올림 1 클럭)

1. Hardware Manager → Open Target → Auto Connect → Program Device : Bitstream = ILA `.bit`, Debug probes file = 같은 폴더 `.ltx` → Program
2. ILA 화면 (hw_ila_1) Trigger Setup 에 두 줄 추가
   - `w_tick_10ms` == `1` (Binary)
   - `w_cnt_msec` == `99` (Radix 를 Unsigned Decimal 로 바꾼 뒤 99, 또는 Hex `63`)
   - 둘 다 걸리게 (Global AND, 기본값)
3. Settings : Trigger position = 512 (창 1024 의 가운데)
4. ComPortMaster 로 `/mod s_ms` → `/btn R` (스톱워치가 흘러야 함) → ILA 의 Run Trigger (▶)
5. 파형에서 `w_cnt_msec` · `w_cnt_sec` 를 Unsigned Decimal 로, 트리거 지점 (T) 주변 3 샘플 확대 → 캡처

| 샘플 | Before 예상 | After 예상 |
|---|---|---|
| T | msec 99 · sec S · w_tick_sec 0 | msec 99 · sec S · **w_tick_sec 1** (같은 클럭에 올림) |
| T+1 | msec 0 · **sec S (아직 안 바뀜)** · w_tick_sec 1 | msec 0 · **sec S+1** |
| T+2 | msec 0 · sec S+1 | msec 0 · sec S+1 |

- Before 의 T+1 한 샘플 (10 ns) 이 "1/100 초는 0 인데 초는 그대로" = L6 의 원인. After 는 이 샘플이 없어짐.
- 예상 표는 코드에서 읽은 것이고 보드로는 아직 안 찍음. ILA 는 신호를 레지스터 뒤에서 보기 때문에 샘플 번호가 하나씩 밀려 보일 수 있음 — 둘의 **차이 (1 샘플 있음 / 없음)** 를 본다.
- ILA 비트 구현 : Before WNS +0.750 ns · After +0.513 ns (위반 0). 발표 수치 (LUT · WNS) 는 ILA 없는 비트 값을 씀.
