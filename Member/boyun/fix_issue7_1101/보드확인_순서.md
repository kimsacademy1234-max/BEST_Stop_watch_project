# 보드 확인 순서 — 결함 8 건 수정 Before / After (11/01)

- 한 줄에 한 동작. 위에서부터 그대로 따라 하면 됨.
- **스위치는 `/mod` 를 한 번이라도 보내면 안 먹음** (설계 의도) → 스위치를 쓰는 E6 을 리셋 직후 맨 먼저.
- ILA 비트에도 설계가 다 들어 있어서 **비트는 두 번만** 올림 (Before ILA 비트 → After ILA 비트).

## 찍는 방법

| 항목 | 찍는 방법 |
|---|---|
| E6 · G3 · G7 · D7 | **영상** (지난번처럼) : 터미널 화면 녹화 (`Win + Alt + R`) + 휴대폰 (FND · LED · 스위치 · 버튼이 다 보이게). 비트마다 끊지 않고 한 번에 (Before : E6 → G3 → G7 / After : E6 → G3 → G7 → D7) |
| H7 · H9 | 명령 프롬프트 결과 **화면 캡처** (`Win + Shift + S`) |
| L6 | ILA 파형 **화면 캡처** (트리거 지점 확대) |

- 시작 전 ComPortMaster Recv `Clear`, 명령 사이 3 초 이상.
- 다 찍으면 : 영상 4 개 (화면 녹화 2 + 휴대폰 2) + 캡처 6 장 (H7 · H9 · L6 × Before / After) → 자막 넣어 Before / After 로 합침.
