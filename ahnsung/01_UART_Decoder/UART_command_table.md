# UART 명령어 표

> 원본 표의 병합 셀은 그룹의 첫 행에만 값을 적고, 나머지 행은 비워 두었습니다.

| instruction | 모듈 | 명령어 | 기능 | send_sel(3bit) |
|:-----------:|:----:|:------:|:----:|:--------------:|
| **/mod**  | 스톱워치 | s_hm | FND 출력 화면 기능 | x |
|           |          | s_ms |  | x |
|           | 워치     | w_hm |  | x |
|           |          | w_ms |  | x |
|           | 타이머   | t_hm |  | x |
|           |          | t_ms |  | x |
|           | 거리     | dist |  | x |
|           | 온습도   | temp |  | x |
| **/set**  | 워치     | w_hm | 워치 세팅 기능 | x |
| **/off**  | 워치     | w_hm | 워치 세팅 기능 끄기 | x |
| **/get**  | 스톱워치 | _sw  | /auto 기능 x일때 개별값 확인 용도 | 0 |
|           | 워치     | _wh  |  | 1 |
|           | 타이머   | _tm  |  | 2 |
|           | 거리     | dis  |  | 3 |
|           | 온습도   | tem  |  | 4 |
| **/auto** | 스톱워치 | _sw  | 스톱워치 자동 | 0 |
|           | 워치     | _wh  | 워치 자동 | 1 |
|           | 타이머   | _tm  | 타이머 자동 | 2 |
|           | 모두     | all  | 모두 화면 표시 | 0.25ms 간격으로 순환 |
|           | 끄기     | off  | auto 기능 끄기 | x |
| **error** |          |      |  | 7 |

# 스위치 입력 표

| `{SW4 SW3 SW2 SW1 SW0}` | 기능 |
|:-----------------------:|:----:|
| `0 0 0 0 0` | 시계, 12시간, 초.1/100초 |
| `0 0 0 1 0` | 시계, 12시간, 시.분 |
| `0 1 0 0 0` | 시계, 24시간, 초.1/100초 |
| `0 1 0 1 0` | 시계, 24시간, 시.분 |
| `0 X 1 1 0` | 시계 시간 설정 (시.분 점멸) |
| `0 X X 0 1` | 스톱워치, 초.1/100초 |
| `0 X X 1 1` | 스톱워치, 시.분 |
| `1 X X X X` | 타이머 (분.초) |

(X = 무관)
