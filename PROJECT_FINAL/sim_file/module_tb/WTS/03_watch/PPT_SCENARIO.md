## 시나리오 1 : 리셋 뒤 커서 FSM (R · L · U · D) — 프리로드 없음

| 순서 | 입력/동작 | 확인 내용 | 예상 결과 |
|---|---|---|---|
| 1 | rst (1 us) | 리셋 상태 | NORMAL, cursor 3, 12:00 |
| 2 | set_sw2 = 0, R → L → U → D | 설정 OFF 버튼 무시 | tick 4 개 발생, NORMAL 유지 |
| 3 | set_sw2 = 1 | 설정 진입 | NORMAL → SET_MIN_1 |
| 4 | L × 3 | 커서 왼쪽 이동 · 회전 | MIN_1 → MIN_10 → HOUR → MIN_1 |
| 5 | R × 3 | 커서 오른쪽 이동 · 회전 | MIN_1 → HOUR → MIN_10 → MIN_1 |
| 6 | U → D | 상태 유지 (자기 루프) | SET_MIN_1 유지, 분 00 → 01 → 00 |
| 7 | set_sw2 = 0 | 설정 종료 | SET_MIN_1 → NORMAL |

시각 (ms): 1 = 0.001 / 2 = 10 · 20 · 30 · 40 / 3 = 60 / 4 = 70 · 80 · 90 / 5 = 110 · 120 · 130 / 6 = 150 · 160 / 7 = 180

슬라이드 파형 설명 (개조식):
- 설정 OFF (set_sw2 = 0): R · L · U · D tick 이 와도 NORMAL 유지
- set_sw2 = 1 → SET_MIN_1 부터 시작
- L: MIN_1 → MIN_10 → HOUR → MIN_1 / R: 반대 방향 회전
- U · D: 상태 그대로, 커서 자리 값만 ±1
- set_sw2 = 0 → NORMAL 복귀

wcfg 신호: clk · rst / set_sw2 / btn_R · R_tick … btn_D · D_tick / n_state · c_state · o_wt_cursor · o_wt_up · o_wt_down / o_wt_hour · o_wt_min

## 시나리오 2 : R · L · U · D 동시 입력 — 시각 (ms) 1 = 0.001 · 5 / 2 = 10 / 3 = 20 / 4 = 30 / 5 = 40

설계 (watch_control_unit): 커서는 set_sw2 = 0 > L > R 우선, U + D 같은 클럭 = 무효, 이동과 ± 는 같은 클럭에 둘 다 (± 는 누르기 전 자리)

| 순서 | 입력/동작 | 확인 내용 | 예상 결과 |
|---|---|---|---|
| 1 | rst, set_sw2 = 1 | 설정 진입 | SET_MIN_1, 12:00 |
| 2 | L + R 동시 | L 우선 | SET_MIN_1 → SET_MIN_10 |
| 3 | U + D 동시 | ± 무효 | up · down 0, 12:00 유지 |
| 4 | L + U 동시 | 이동 + 증가 같은 클럭 | SET_HOUR, 분 +10 → 12:10 |
| 5 | R + L + U + D 동시 | L 우선 + ± 무효 | SET_HOUR → SET_MIN_1, 12:10 유지 |

## 시나리오 3 : 1 초 정확도 (프리로드 · 버튼 없음) — 시각 1 = 1 us / 2 = 10.000995 ms / 3 = 1.000001015 s / 4 = 2.000001015 s

| 순서 | 입력/동작 | 확인 내용 | 예상 결과 |
|---|---|---|---|
| 1 | rst 해제 | 시계 시작 | 12:00:00.00 |
| 2 | 대기 | o_tick_10ms 간격 | 10 ms (100 MHz × 1,000,000) |
| 3 | 대기 | 1/100 초 99 → 00 | 리셋 1 s 뒤 초 0 → 1 |
| 4 | 대기 | 초 1 → 2 간격 | 정확히 1,000,000,000 ns |

## 시나리오 4 : 경계값 분 00 ↔ 59 (프리로드 없음 — 리셋값 12:00 에서 D 한 번이면 경계) — 시각 (ms) 1 = 0.001 · 5 / 2 = 10 / 3 = 20 / 4 = 30 / 5 = 40

| 순서 | 입력/동작 | 확인 내용 | 예상 결과 |
|---|---|---|---|
| 1 | rst, set_sw2 = 1 | 분 일의 자리 선택 | SET_MIN_1, 12:00 |
| 2 | U | 보통 증가 | 12:01 |
| 3 | D | 보통 감소 | 12:00 |
| 4 | D | 경계 아래로 (내림 없음) | **12:59** (시 12 그대로) |
| 5 | U | 경계 위로 (올림 없음) | **12:00** (시 12 그대로) |

## 시나리오 5 : FND 점멸 (시.분 화면) — 시각 (s) 1 = 0.000001 · 0.005 / 2 = 1.0 / 3 = 2.0 / 4 = 3.005

| 순서 | 입력/동작 | 확인 내용 | 예상 결과 |
|---|---|---|---|
| 1 | rst, display_mode_sw1 = 1, set_sw2 = 1 | 커서 0 점멸 | AN0 빈칸 "12.0_" (msec ≥ 50 동안) |
| 2 | L | 커서 1 점멸 | AN1 빈칸 "12._0" |
| 3 | L | 커서 2 점멸 | AN2 빈칸 "1_.00" |
| 4 | set_sw2 = 0 | 점멸 해제 | "12.00" 고정 (가운데 점만 점멸) |
