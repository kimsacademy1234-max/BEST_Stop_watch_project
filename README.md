# stop_watch project

## 팀원

- 정보윤, 이종혁, 정안성, 견다혜

## 역할 (각자 모듈 설계)

| 담당 | 모듈 / 기능 |
|------|-------------|
| 이종혁 | SW3 입력 시 12시 → 24시 전환 기능을 STW-CONT UNIT에 추가 (랩 타임) |
| 정보윤 | 워치 스테이트 머신 |
| 정안성 | SW2 assert 시 FND 점멸 기능 |
| 견다혜 | 학교 시험 공부 |

## 목표

- 기본 목표: 스톱워치 설계 + 모듈 검증
- 시간이 되면: 타이머 기능까지 구현

## 일정 (Time Flow)

**금요일 2시까지: 설계 완성 및 검증 완료**

1. 시뮬레이션 검증
   - tick freq를 올리지 않는다.
   - 실제 time 기준으로 시뮬레이션하여 기능 동작이 맞는지 확인한다.
2. 2시에 보드 동작 확인
   - 동작하지 않으면 보드 교체
   - 트러블 슈팅 방법 토의
   - 계속 동작하지 않으면 될 때까지 시뮬레이션을 본다.
3. 구현 완료 후 top 검증 토의 (with AI)
   - 각 시나리오(TB)별 역할 분담 후 각자 검증
4. 발표 자료 (5번 자료)
   - 파형 캡처 및 무엇을 보여주려고 했는지 박스와 화살표로 표현한다.
