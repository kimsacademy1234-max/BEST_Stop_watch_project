준비 — 연습 폴더와 파일 만들기

터미널(WSL/리눅스)에 아래 블록을 통째로 복사해서 붙여넣고 Enter 를 누르세요. ~/vim_practice 폴더에 연습 파일 2개가 생깁니다.

# 1) 연습 폴더 만들고 들어가기
mkdir -p ~/vim_practice && cd ~/vim_practice

# 2) adder.v 만들기
cat > adder.v << 'EOF'
module adder (
    input  [3:0] a,
    input  [3:0] b,
    output [4:0] sum
);
    assign sum = a + b;
endmodule
EOF

# 3) tb_adder.v 만들기
cat > tb_adder.v << 'EOF'
module tb_adder;
    reg  [3:0] a, b;
    wire [4:0] sum;

    adder dut (.a(a), .b(b), .sum(sum));

    initial begin
        a = 4'd1; b = 4'd2; #10;
        a = 4'd3; b = 4'd4; #10;
        a = 4'd5; b = 4'd6; #10;
        a = 4'd7; b = 4'd8; #10;
        $finish;
    end
endmodule
EOF

# 4) 확인 — adder.v  tb_adder.v 가 보이면 성공
ls

PDF에서 복사하면 들여쓰기 칸 수가 조금 달라질 수 있는데, 실습에는 문제 없습니다. 실습 중 파일을 망쳤다면 위 블록을 다시 붙여넣으면 처음 상태로 돌아갑니다.
