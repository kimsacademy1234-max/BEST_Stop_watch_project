창 분할 (Split) 파일 두 개 나란히 보기

:vs / :vsplit현재 파일을 세로로 분할 (좌우)
:vs 파일명다른 파일을 오른쪽 창에 열기
:sp / :split가로로 분할 (위아래)
:new / :vnew빈 버퍼로 가로 / 세로 분할
창 이동
Ctrl+w w다음 창으로 순환 이동
Ctrl+w W이전 창으로 이동
Ctrl+w hjkl왼 / 아래 / 위 / 오른쪽 창으로
Ctrl+w p직전에 있던 창으로
닫기 · 배치
Ctrl+w q / :q현재 창 닫기
Ctrl+w o / :only현재 창만 남기고 모두 닫기
Ctrl+w x옆 창과 위치 교환
Ctrl+w HJKL현재 창을 맨 왼/아래/위/오른쪽으로
Ctrl+w T현재 창을 새 탭으로 떼어내기
크기 조절
Ctrl+w =모든 창 크기 균등하게
Ctrl+w > / <너비 +1 / −1 (10 먼저 치면 10칸)
Ctrl+w + / -높이 +1 / −1
Ctrl+w | / _너비 / 높이 최대화
:vertical resize 80너비를 80칸으로 지정
TIP 터미널에서 바로 분할로 열기: vim -O a.v b.v (좌우), vim -o (위아래), vim -p (탭)

검색 · 치환

/단어아래 방향 검색 (?는 위 방향)
n / N다음 / 이전 결과
* / #커서 위 단어를 아래 / 위로 검색
:noh검색 하이라이트 끄기
치환
:%s/old/new/g파일 전체 old → new
:%s/old/new/gc하나씩 확인하며 치환 (y/n)
:%s/\<cnt\>/count/g단어 단위로만 치환 (cnt_r은 그대로)
:10,20s/a/b/g10~20번째 줄에서만 치환
Visual 선택 → :s/a/b/g선택한 영역만 치환 (:'<,'> 자동 입력됨)
TIP 신호 이름 일괄 변경: 이름 위에서 * → :%s//새이름/g (검색어 비우면 직전 검색어 사용)

여러 줄 한 번에 주석 달기 Visual Block

주석 달기
① Ctrl+v줄 맨 앞에서 Visual Block 시작
② j 반복 (또는 5j)주석 달 줄까지 아래로 선택
③ I → // 입력대문자 I 후 주석 문자 입력
④ Esc선택한 모든 줄에 적용됨
주석 지우기
Ctrl+v → j… → l → d// 두 글자 폭만큼 선택 후 삭제
같은 방식으로 A를 쓰면 선택한 줄들의 끝에 한꺼번에 덧붙이기 ($로 끝까지 선택 후)

버퍼 · 탭 여러 파일 다루기

:e 파일명파일 열기 (Tab으로 경로 자동완성)
:ls열려 있는 버퍼 목록
:b 2 / :b fifo2번 버퍼 / 이름에 fifo 포함된 버퍼로
:bn / :bp다음 / 이전 버퍼
Ctrl+^직전 파일과 왔다갔다
:tabnew 파일명새 탭에서 열기
gt / gT다음 / 이전 탭
:tabclose현재 탭 닫기
gf커서 위 파일 경로를 바로 열기 (`include 등)

:vert diffsplit b.vVim 안에서 비교 창 열기
]c / [c다음 / 이전 차이점으로
do / dp상대 내용 가져오기 / 내 내용 보내기
:diffupdate차이 다시 계산

매크로 · 기타

qa … qa에 동작 녹화 시작 … 종료
@a / 10@a매크로 실행 / 10번 반복
:!lsVim 안에서 셸 명령 실행
:r 파일명다른 파일 내용을 커서 아래 삽입
Ctrl+z → fg잠시 터미널로 나갔다가 복귀
:set paste붙여넣기 시 들여쓰기 꼬임 방지 (끝나면 :set nopaste)
:set nu / :set nonu줄 번호 켜기 / 끄기
:help 명령내장 도움말 (예: :help CTRL-W)

추천 ~/.vimrc 복사해서 바로 사용

" 기본 표시
syntax on
filetype plugin indent on
set number            " 줄 번호
set cursorline        " 현재 줄 강조
set ruler showcmd
" 검색
set hlsearch incsearch ignorecase smartcase
" 들여쓰기 (스페이스 4칸)
set tabstop=4 shiftwidth=4 expandtab autoindent
" 분할 방향: 새 창은 오른쪽/아래로
set splitright splitbelow
" 마우스 사용 (창 크기 드래그 가능)
set mouse=a
" Verilog begin/end 도 % 로 점프
packadd! matchit
" 탐색기 배너 숨기고 트리 보기
let g:netrw_banner = 0
let g:netrw_liststyle = 3
