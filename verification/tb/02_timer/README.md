# 02_timer — 타이머 검증 기준 (발표: 정보윤)

## 이 기능의 사양 (판정의 기준)

| 상태 | 버튼 (sw4 = 1, 타이머 화면) | 동작 |
|---|---|---|
| 설정(SET) | U / R / D | +10 초 / +1 분 / +10 분. **최대 59:59** (넘으면 59:59 로 고정) |
| 설정(SET) | L | 시작. 남은 시간이 0 이면 시작 안 함 |
| 동작(RUN) | L | 취소 → 00:00, 설정 상태 |
| 동작(RUN) | U / R / D | 무시 |
| 알람(ALARM) | 아무 버튼 | 알람 끄기 → 설정 상태 (더하기로는 안 쓰임) |

- 0 이 되면 알람: LED 16 개가 0.5 초마다 전부 켜짐/꺼짐 (어느 화면에서나)
- 화면은 sw1 과 상관없이 항상 "분.초"
- sw4 = 1 이면 sw0 보다 우선 (타이머 화면)
- 다른 화면으로 가도 계속 줄어들고, 다른 화면 버튼으로는 알람이 안 꺼진다
- 10 ms tick 은 공용(항상 흐름) → 설정 T 초는 실제로 (T − 10 ms) ~ T 사이에 끝난다
- LED: led5 = 타이머 화면, led6 = 동작 중

## 공통 판정 방법

- 버튼 1 회 = 5 ms 누름 + 5 ms 뗌
- **프리로드**: 01:00.00 같은 경계 값을 타이머 레지스터에 직접 넣고 바로 다음 tick 을 본다 (주파수는 그대로). 콘솔에 `[INFO][PRELOAD]`
- 콘솔 끝 `[SUMMARY] ... => PASS` 면 통과. `[FAIL]` 시각으로 파형 이동

### 파형에 넣을 신호
| 신호 | 의미 |
|---|---|
| `btnR` `btnL` `btnU` `btnD`, `wv_btn_pulse` | 버튼 핀 / 인식된 눌림 |
| `wv_tm_min`, `wv_tm_sec`, `wv_tm_msec` | 남은 시간 (Radix = Unsigned Decimal) |
| `wv_tm_run` | 1 = 동작 중 |
| `wv_tm_alarm` | 1 = 알람 중 |
| `led` | 16 비트 (알람 중 FFFF / 0000 반복) |
| `sw_timer`, `sw_mode` | 화면 선택 |
| `wv_wt_msec` | 알람 점멸 박자 (시계 1/100초 ≥ 50 이면 켜짐) |

## tb_tm_1_add_cap.sv — 더하기 · 상한 59:59

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | 리셋 후 sw4 = 1 | 화면 = 분.초(`w_disp_mode` = 1), LED = `0020`(led5), FND "00.00" | 화면 · LED 사양 |
| P2 | 00:00 에서 L | 시작 안 함 (`wv_tm_run` = 0, 알람 없음) | 0 에서 시작하면 바로 알람이 울리는 것 방지 |
| P3 | U × 5 → U 1 번 더 | 00:50 → **01:00** (FND "01.00") | 초 → 분 올림 |
| P4 | R → D → U | 01:00 → 11:00 → 11:10 | 버튼별 더하기 양 |
| P5 | D × 5 → R × 9 → U × 5 → U | 50:00 → 59:00 → 59:50 → **59:59** (60:00 이 아님, FND "59.59") | 상한 판정은 초 올림까지 더한 분으로 해야 한다 |
| P6 | 59:59 에서 U, R, D 각각 | 전부 59:59 유지 | 상한 고정 |
| P7 | 버튼으로 52:10 만든 뒤 D → R | 52:10 + 10 분 = 62:10 → **59:59**, R 에도 59:59 | 큰 단위로 넘칠 때도 고정 |

## tb_tm_2_countdown_alarm.sv — 실제 카운트다운 · 알람 (시뮬 약 12 초, Phase 별 실행 권장)

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | U(00:10) → L, 프리로드 없이 끝까지 | `wv_tm_run` 상승 → `wv_tm_alarm` 상승 간격 = **9.990 초 초과 ~ 10.000 초(+1 클럭)**, 알람 때 00:00.00 · 동작 꺼짐, 동작 중 led6 = 1 | 실제 시간 정확도. 공용 tick 때문에 최대 10 ms 일찍 끝날 수 있음 |
| P2 | 알람 상태로 1.5 초, 50 ms 마다 LED 확인 (P1 에 이어서) | 시계 1/100초 ≥ 50 이면 `led` = FFFF, 아니면 0000. 1.5 초 뒤에도 알람 유지 | 알람 LED 패턴, 저절로 꺼지지 않음 |
| P3 | D 로 알람 끄기 (P2 에 이어서) | 알람 꺼짐 · 설정 상태, 값 **00:00 그대로**(10 분 안 더해짐), LED = `0020` | 끄는 버튼이 더하기로 겹쳐 쓰이지 않는지 |
| P4 | 동작 중 01:00.00, 10:00.00 프리로드 | 다음 tick 에 **00:59.99**, **09:59.99** (FND "09.59") | 빼기의 빌림 |

※ P2 · P3 는 P1 의 알람을 이어서 쓴다. `RUN_PHASE = 1` 로 실행하면 P1~P3 가 같이 돈다.

## tb_tm_3_cancel_background.sv — 취소 · 백그라운드 · 버튼 게이팅

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | 01:00 시작 후 U, R, D | 값이 늘지 않음 (약 30 ms 만큼만 줄어듦), 동작 유지 | 동작 중에는 더하기 무시 |
| P2 | 동작 중 L | **00:00.00**, 설정 상태, 알람 없음 | 취소 |
| P3 | 01:00 시작 → 시계 화면으로 → 00:00.30 프리로드 | 시계 화면에서도 계속 줄어들고 알람 발생, 시계 화면에서 LED 가 알람 패턴, FND 는 시계 "12.00" | 백그라운드 동작, 알람은 어느 화면에서나 LED 로 |
| P4 | 알람 중 시계 화면에서 U/D/L/R, 스톱워치 화면에서 D | 알람 **계속 켜짐** | 다른 화면 버튼은 타이머로 안 감 |
| P5 | sw4 = 1 & sw0 = 1 → R | 타이머가 선택됨(`w_sel_tm` = 1), R 로 알람 꺼짐 · 1 분 안 더해짐, LED = `0020` | sw4 우선 |
