# 03_watch — 시계 검증 기준 (발표: 정안성)

## 이 기능의 사양 (판정의 기준)

- 리셋 = **12:00:00.00 (오후 12시)**, 기본 12시간 표시
- 설정 모드 (sw0 = 0 시계 화면, sw2 = 1)

| 버튼 | 동작 |
|---|---|
| L / R | 커서 이동. L: 분 일 → 분 십 → 시 → 분 일, R: 반대 방향 (양 끝에서 돌아감) |
| U / D | 커서 자리만 +/−. 분 일 ±1, 분 십 ±10, 시 ±1. **윗자리로 올림/내림 없음** (분 59 + 1 → 00, 시는 그대로) |
| U + D 동시 | U 우선 |

- 설정에 들어가면 항상 분 일의 자리(커서 0)부터. 초와 1/100초는 설정할 수 없다
- 설정 중에도 시계는 계속 흐른다
- 설정 모드가 아닐 때(sw2 = 0)는 버튼을 무시한다. 다른 화면(스톱워치/타이머)의 버튼도 시계로 오지 않는다
- sw3 = 0 이면 12시간 표시(0시 → 12, 13시 → 1), sw3 = 1 이면 24시간
- 설정 중 커서 자리가 0.5 초마다 빈칸으로 점멸 (시.분 화면일 때)
- LED: led0 = 시계 화면, led2/led3 = 시.분 / 초.1/100 화면, **led15 = 오후** (시계 화면 · 12시간 표시 · 12시 이후)

## 공통 판정 방법

- 버튼 1 회 = 5 ms 누름 + 5 ms 뗌
- **프리로드**: 23:59:59.95 같은 경계 바로 앞 값을 카운터에 직접 넣고 그 직후부터 본다 (주파수는 그대로 100 MHz). 콘솔에 `[INFO][PRELOAD]`
- 1 초 정확도(P1 of wt_2)는 프리로드 없이 실제로 흘려서 잰다
- 콘솔 끝 `[SUMMARY] ... => PASS` 면 통과. `[FAIL]` 시각으로 파형 이동

### 파형에 넣을 신호
| 신호 | 의미 |
|---|---|
| `btnR` `btnL` `btnU` `btnD`, `wv_btn_pulse` | 버튼 핀 / 인식된 눌림 |
| `wv_wt_hour`, `wv_wt_min`, `wv_wt_sec`, `wv_wt_msec` | 시계 내부 값 (24시간 기준, Radix = Unsigned Decimal) |
| `wv_wt_set` | 1 = 설정 중 |
| `wv_wt_cursor` | 0 분 일 · 1 분 십 · 2 시 · 3 없음 |
| `wv_tick_10ms` | 10 ms tick |
| `fnd_com`, `fnd_font`, `wv_fnd_slot` | FND 출력 (점멸 확인) |
| `led[15]`, `led` | 오후 표시, LED 전체 |
| `sw_set`, `sw_24h`, `sw_display_mode` | 설정 · 12/24 · 화면 |

## tb_wt_1_set_ui.sv — 설정 UI

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | 리셋 | 12:00:00.00, 커서 3(없음), 설정 아님, LED = `8009`(led0 · led3 · led15) | 보드 켜자마자 보이는 첫 화면 |
| P2 | 설정 아님(sw2 = 0)에서 U, D, L, R | 시간 12:00 그대로, 커서 3 | 실수로 시간이 바뀌지 않게 |
| P3 | sw2 = 1 → L × 3 → R × 3 | 진입 시 커서 0 / L: 0 → 1 → 2 → 0 / R: 0 → 2 → 1 → 0 | 커서 이동 전 경로와 양 끝 회전 |
| P4 | 커서 0 에서 12:59 프리로드 → U → D → D | 12:00 (**시는 13 이 아님**) → 12:59 → 12:58 | 설정은 그 자리만 돈다 |
| P5 | 커서 1 에서 12:55 프리로드 → U → D → D | 12:05 → 12:55 → 12:45 | 분 십 ±10 회전 |
| P6 | 커서 2 에서 U → 23:30 프리로드 → U → D | 13:00 → 00:30 (**분 그대로**) → 23:30 | 시 회전 |
| P7 | U 와 D 를 같은 순간 누름 | U · D 펄스가 같은 클럭(`wv_btn_pulse` = 1100), 결과 +1 (12:01) | U 우선 사양 |
| P8 | 커서를 시로 옮긴 뒤 sw2 끔 → 다시 켬 | 끄면 커서 3, 다시 켜면 **커서 0** | 재진입 시 항상 분 일부터 |
| P9 | sw2 = 1 인 채로 스톱워치 화면 / 타이머 화면에서 버튼 | 시계 시간 · 커서 안 바뀜, 시계는 계속 흐름 | 화면별 버튼 게이팅 |

※ TB 내내 상시 감시: 초 · 1/100초 카운터에는 설정 신호가 한 번도 들어가지 않아야 한다 (초 설정 없음 사양).

## tb_wt_2_rollover.sv — 1 초 정확도 · 올림 경계

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | 리셋 후 프리로드 없이 2 초 | 초가 바뀌는 간격 = 정확히 **1,000,000,000 ns**, 2 초 뒤 12:00:02.00 | 실시간 시계 정확도 (1 초 = 1억 클럭) |
| P2 | 00:00:59.95 프리로드 | tick 4 번 뒤 00:00:59.99 → 5 번째 tick 에 **00:01:00.00** | 초 → 분 올림 |
| P3 | 00:59:59.95 프리로드 | 00:59:59.99 → **01:00:00.00** | 분 → 시 올림 |
| P4 | 23:59:59.95 프리로드 (시.분 화면, 12시간) | 프리로드 직후 led15 = 1(오후) → **00:00:00.00**, led15 = 0(오전), FND "12.00" | 4 단 올림이 한 tick 에 연달아 일어나는 유일한 순간 + 자정 = 오전 12시 |
| P5 | 설정 모드에서 23:59:59.95 프리로드 | 설정 중이어도 00:00:00.00 으로 넘어감 | 설정 중에도 시계가 흐르는 현재 동작을 기록 |

P4 파형 포인트: tick 직후 4 클럭 동안 23:59:59.99 → 23:59:59.00 → 23:59:00.00 → 23:00:00.00 → 00:00:00.00 으로 한 자리씩 넘어간다 (올림이 1 클럭씩 늦게 전달되는 구조, 30 ns 라 눈에는 안 보임).

## tb_wt_3_display_12h.sv — 12/24 표시 · FND · 점멸 · LED

| Phase | TB 가 하는 것 | 정상 동작 기준 | 왜 |
|---|---|---|---|
| P1 | 시를 0~23 으로 바꿔 가며 sw3 = 0 / 1 (48 경우) | 12시간: 0 → 12, 1~12 → 그대로, 13~23 → −12 / 24시간: 그대로. led15 = 12시간 & 12시 이상 | 0 과 12 가 둘 다 "12" 로 보이는 비선형 변환 |
| P2 | 12:34, 13:05 프리로드 | FND "12.34" / 24시간 "13.05" / 12시간 "01.05" + led15 = 1 | 화면 문자열 |
| P3 | 12:34 에서 설정 모드, 커서 0 · 1 · 2 각각 1 초 | 1/100초 ≥ 50 동안 커서 자리만 빈칸: "12.3_" / "12._4" / "1_.34", < 50 이면 "12.34". sw2 끄면 점멸 없음 | 설정 점멸 (FND 연동) |
| P4 | sw1 × sw3 × 오전/오후(9시, 21시) 8 경우 | LED = led0 + (sw1 ? led2 : led3) + (12시간 & 오후 ? led15) | LED 사양 |
